# BEN AI Trading Robot

Dashboard crypto berbasis web, mobile-friendly, gratis, dan read-only.

## Fitur
- Monitoring BTC/IDR dan ETH/IDR dari API publik CoinGecko.
- Sinyal BUY / SELL / HOLD berbasis EMA 9, EMA 21, dan RSI 14.
- Grafik historis 7 hari dan refresh otomatis setiap 60 detik.
- Tidak meminta API key, password exchange, seed phrase, atau private key.
- Tidak mengirim order dan tidak melakukan transaksi.

## Menjalankan
Buka `index.html` melalui GitHub Pages atau server web statis. Tidak ada instalasi server/backend.

## Aktifkan GitHub Pages
1. Buka Settings pada repository.
2. Pilih Pages.
3. Pada Build and deployment, pilih Deploy from a branch.
4. Pilih branch `main` dan folder `/ (root)`, lalu Save.
5. Tunggu proses publikasi. URL proyek: https://3pitribahgiajaya.github.io/ben-ai-trading-bot/

## Catatan
Aplikasi memerlukan koneksi internet dan API publik CoinGecko. Jika API membatasi permintaan atau sedang gangguan, tekan tombol Perbarui data dan coba lagi nanti. Indikator adalah alat bantu, bukan jaminan hasil atau nasihat investasi.
